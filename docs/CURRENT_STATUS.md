# وضعیت فعلی پروژه مارکت‌پلتفرم

**آخرین به‌روزرسانی:** ۱۵ نوامبر ۲۰۲۶  
**نسخه فعلی بک‌اند:** 0.1.7+  
**ریپو:** https://github.com/reza13610620/market-platform

---

## ۱. خلاصه کلی

پلتفرم مارکت‌پلیس عمومی با مدل ناشناس تا لحظه مشاهده اطلاعات تماس.

**فاز فعلی:** وب + API کامل برای چرخه اصلی خریدار/فروشنده  
**فاز بعدی:** اپ موبایل بومی (اندروید + iOS) — فاز جداگانه

---

## ۲. آنچه تا الان کامل شده (بک‌اند)

### احراز هویت
- درخواست و تأیید OTP
- صدور JWT (اعتبار ۳۰ روز)
- میدل‌ویر `requireAuth`

### پروفایل کاربر
- `GET /api/me`
- `PATCH /api/me` (ویرایش نام، شهر، بیو و ...)

### کیف پول
- `GET /api/wallet` (موجودی + قفل‌شده + قابل استفاده)
- `GET /api/wallet/transactions`

### درخواست کالا (خریدار)
- `POST /api/requests` — ثبت درخواست
- `GET /api/requests/my` — لیست درخواست‌های من

### استخر و پیشنهاد (فروشنده)
- `GET /api/pool` — استخر درخواست‌ها
  - پارامتر `only_my_supply=1` برای فیلتر بر اساس لیست تأمین
- `POST /api/offers` — ثبت پیشنهاد قیمت

### مشاهده پیشنهادها و اطلاعات تماس (نقطه درآمدی)
- `GET /api/requests/:id/offers` — پیشنهادهای یک درخواست (ناشناس)
- `POST /api/offers/:id/reveal` — نمایش اطلاعات فروشنده + کسر سهمیه
- `GET /api/contact/quota` — سهمیه باقی‌مانده

### لیست تأمین فروشنده
- `GET /api/supply`
- `POST /api/supply`
- `DELETE /api/supply/:productId`

---

## ۳. آنچه تا الان کامل شده (فرانت‌اند)

پوشه: `frontend/`

- سیستم تم رنگی هوشمند (بانوان / آقایان / خنثی)
- صفحه ورود با OTP
- داشبورد ریسپانسیو با منوی کناری و موبایل
- صفحه خانه با دسترسی سریع
- پروفایل + ویرایش + انتخاب تم
- کیف پول + نمایش سهمیه
- ثبت درخواست کالا
- لیست درخواست‌های من
- **صفحه جزئیات درخواست** (کامل — وضعیت + پیشنهادها + نمایش اطلاعات)
- استخر پیشنهادها با فیلتر «فقط لیست تأمین من»
- لیست تأمین فروشنده

ظاهر: مدرن، آرامش‌بخش، کارت‌های نرم، انیمیشن ملایم

## ۴. ساختار دیتابیس (خلاصه)

جداول کلیدی آماده:

| بخش | جداول |
|-----|--------|
| کاربران | users, user_profiles, user_wallets, user_subscriptions |
| اشتراک | subscription_plans (با benefits_json) |
| کالا | categories, products, product_barcodes, seller_supply_list, product_review_queue, user_favorites |
| درخواست | requests, request_items, request_offers, contact_views |
| سفارش (فاز بعد) | orders, escrow_transactions, wallet_transactions |
| اعتماد | reviews, penalties |
| پشتیبانی | tickets, ticket_messages |
| سیستم | otp_codes, notifications, activity_logs |

---

## ۵. قوانین مهم کسب‌وکار (فاز فعلی)

- ناشناس بودن تا لحظه «نمایش اطلاعات تماس»
- درآمد اصلی فاز فعلی: فروش سهمیه مشاهده اطلاعات تماس
- سهمیه از benefits_json پلن اشتراک خوانده می‌شود
- فروشنده فقط یک پیشنهاد فعال روی هر درخواست می‌تواند داشته باشد
- لیست تأمین فروشنده پایه فیلتر استخر است

---

## ۶. نیازهای ثبت‌شده برای ادامه (هنوز پیاده نشده)

### اولویت بالا
1. **پیشنهاد کالای جدید توسط کاربر**  
   - اگر کالا وجود نداشت، کاربر بتواند آن را پیشنهاد دهد  
   - نتیجه (تأیید/رد) به او اطلاع‌رسانی شود  
   - جدول `product_review_queue` از قبل وجود دارد

2. **سیستم تیکت و چت پشتیبانی**  
   - جداول `tickets` و `ticket_messages` آماده است  
   - نیاز به API و رابط کاربری دارد

### اولویت متوسط
3. اعلان‌های واقعی (پوش + پیامک + درون‌برنامه)
4. صفحه مدیریت پلن و ارتقا
5. فیلترهای بیشتر استخر (شهر، تاریخ و ...)

### فاز جداگانه
6. اپلیکیشن موبایل بومی اندروید و iOS
7. سیستم سفارش + اسکرو + پرداخت واقعی کالا

## ۷. نکات فنی مهم

- بک‌اند: Cloudflare Workers + D1
- فرانت: React + Vite + TypeScript + Tailwind
- تم رنگی بر اساس جنسیت در `ThemeContext` مدیریت می‌شود
- همه تصمیم‌های مهم باید در پوشه `docs/` ثبت شوند

## ۸. مسیرهای پیشنهادی ادامه کار

1. پیاده‌سازی «پیشنهاد کالای جدید» (چون جدولش آماده است)
2. سپس سیستم تیکت ساده
