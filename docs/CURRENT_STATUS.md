# وضعیت فعلی پروژه مارکت‌پلتفرم

**آخرین به‌روزرسانی:** ۱۹ نوامبر ۲۰۲۶  
**نسخه فعلی:** 0.5.x  
**ریپو:** https://github.com/reza13610620/market-platform

---

## ۱. خلاصه کلی

پلتفرم مارکت‌پلیس عمومی با مدل **ناشناس تا لحظه مشاهده اطلاعات تماس**.

**فاز فعلی:** وب + API کامل برای چرخه اصلی خریدار/فروشنده (هماهنگی خارج از پلتفرم)  
**فاز بعدی (هنوز شروع نشده):** درگاه پرداخت واقعی، اسکرو، اپ موبایل بومی، SMS واقعی

---

## ۲. قانون نقش‌ها (نهایی – ۱۹ نوامبر ۲۰۲۶)

- هیچ دکمه «فعال‌سازی فروشنده» وجود ندارد.
- هر کاربری که **درخواست** ثبت کند → در نقش خریدار عمل کرده.
- هر کاربری که **پیشنهاد قیمت** بدهد → در نقش فروشنده عمل کرده.
- منوها برای همه باز است.
- هنگام ثبت پیشنهاد، سیستم در صورت نیاز `is_seller = 1` را خودکار تنظیم می‌کند.

---

## ۳. آنچه کامل شده (بک‌اند + فرانت)

### احراز هویت و کاربر
- OTP + JWT
- پروفایل + ویرایش
- کیف پول (موجودی + قفل‌شده)
- پلن‌های اشتراک + ارتقا شبیه‌سازی‌شده

### چرخه اصلی معامله (فاز فعلی)
- ثبت درخواست کالا
- استخر درخواست‌ها + فیلترها
- ثبت پیشنهاد قیمت + لغو با پنالتی تصاعدی
- مشاهده اطلاعات تماس (کسر سهمیه) + اعلان به فروشنده
- ایجاد سفارش سبک هنگام reveal
- تکمیل معامله + بازخورد دوطرفه + امتیاز سیستمی

### کاتالوگ و کالا
- پیشنهاد کالا توسط کاربر
- صف بررسی AI (stub) + ادمین
- تأیید → ورود به کاتالوگ اصلی
- لیست تأمین فروشنده

### پشتیبانی و اعتماد
- تیکت پشتیبانی (سمت کاربر کامل)
- پنالتی تصاعدی
- امتیاز اعتبار + برچسب کیفی
- دستیار هوشمند (فقط پلن طلایی و ویژه)

### فرانت‌اند
- تم رنگی بر اساس جنسیت
- داشبورد ریسپانسیو
- صفحات: خانه، پروفایل، کیف پول، درخواست‌ها، استخر، تأمین، پیشنهاد کالا، تیکت، اعلان، پلن، معاملات، دستیار هوشمند، مقایسه قیمت

---

## ۴. تعریف کالا توسط کاربران

طراحی کامل در `docs/USER_PRODUCT_SUGGESTION_v1.md` و `docs/AI_PRODUCT_REVIEW_FLOW_v1.md`  
مرحله ۱ پیاده‌سازی شده:
- کاربر پیشنهاد می‌دهد
- AI stub بررسی می‌کند
- ادمین تأیید/رد/اصلاح می‌کند
- در صورت تأیید وارد `products` می‌شود

## ۵. باقی‌مانده مهم فاز فعلی (ساده)

- پنل پاسخ تیکت ادمین (در حال تکمیل)
- علاقه‌مندی کالا (Favorites)
- فیلترهای بیشتر استخر (در حال تکمیل)
- بهبودهای UX کوچک

- درگاه پرداخت واقعی
- اسکرو و آزادسازی پول
- SMS واقعی
- اپ موبایل بومی
- خرید/فروش هوشمند پیشرفته
