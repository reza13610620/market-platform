# راهنمای اتصال پیامک و درگاه پرداخت

**تاریخ:** ۲۰۲۶-۱۱-۱۵  
**وضعیت:** طراحی کامل — فقط کلید واقعی باقی مانده

---

## ۱. سیستم پیامک (SMS)

### فایل مربوطه
`src/services/sms.ts`

### متغیرهای محیطی مورد نیاز (در `wrangler.toml` یا داشبورد Cloudflare)

```toml
[vars]
SMS_PROVIDER = "kavenegar"          # یا smsir | faraz | mock
SMS_API_KEY = "your-real-api-key"
SMS_SENDER = "1000xxxx"             # در صورت نیاز
SMS_TEMPLATE_OTP = "otp"            # نام قالب یا شناسه قالب
```

### ارائه‌دهندگان پشتیبانی‌شده
| ارائه‌دهنده | وضعیت |
|-----------|--------|
| kavenegar | آماده |
| sms.ir    | آماده |
| faraz     | ساختار اولیه |
| mock      | برای توسعه (الان فعال است) |

### حالت فعلی
تا وقتی `SMS_API_KEY` وارد نشود، سیستم در حالت **mock** کار می‌کند و کد OTP فقط در لاگ چاپ می‌شود.

## ۲. درگاه پرداخت

### فایل مربوطه
`src/services/payment.ts`

### متغیرهای محیطی

```toml
[vars]
PAYMENT_PROVIDER = "zarinpal"           # یا idpay | mock
PAYMENT_MERCHANT_ID = "your-merchant-id"
PAYMENT_CALLBACK_URL = "https://yourdomain.com/api/payment/callback"
PAYMENT_SANDBOX = "true"                # برای تست true بگذارید
```

### درگاه‌های پشتیبانی‌شده
| درگاه     | وضعیت |
|----------|--------|
| زرین‌پال | آماده |
| آیدی‌پی  | آماده |
| mock     | برای توسعه |

### نکته مهم
فعلاً فقط **ساختار و توابع پایه** آماده شده.  
اتصال کامل به کیف پول و شارژ حساب در مرحله بعدی انجام می‌شود.

---

## ۳. کارهایی که شما باید انجام دهید

1. ثبت‌نام در سرویس پیامک و دریافت API Key + قالب OTP
2. ثبت‌نام در درگاه پرداخت و دریافت Merchant ID
3. دادن کلیدها به من (یا خودتان در `wrangler secret` قرار دهید)
4. ثبت دامنه و اعلام آن

بعد از دریافت کلیدها، فقط مقادیر را جایگزین می‌کنیم و سیستم آماده استفاده واقعی می‌شود.
