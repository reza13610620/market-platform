# نکات احراز هویت موبایل و اپلیکیشن

**تاریخ:** ۲۰۲۶-۱۱-۱۳

## خواندن خودکار کد از پیامک

در طراحی اپلیکیشن موبایل (اندروید و iOS) باید این قابلیت وجود داشته باشد:

1. اپ بتواند کد OTP را به صورت **خودکار از پیامک** بخواند و در فیلد مربوطه قرار دهد.
2. همزمان امکان **ورود دستی** کد هم وجود داشته باشد (برای مواقعی که خواندن خودکار کار نکند).

### پیشنهاد فنی:
- اندروید: استفاده از SMS Retriever API یا User Consent API
- iOS: استفاده از قابلیت خواندن یک‌بار کد از پیامک (input mode one-time-code)

این موضوع باید در طراحی UI/UX صفحه ورود در نظر گرفته شود.
